
26자. ASO 관점에서 제목은 Play 검색 가중치가 가장 높은 필드라, 브랜드명(직장비교) 뒤에

- 대안 A(알바 집중): `직장비교 - 알바 시급 비교, 공고 순위 정리` (25자)
- 대안 B(짧게): `직장비교 - 채용공고 비교·순위` (16자)

## 5. ASO 정리

Play는 App Store와 달리 **키워드 입력 칸이 없다.** 색인은 앱 이름 > 짧은 설명 > 전체 설명 순으로
가중치가 걸리므로, 위 세 필드에 키워드를 자연스럽게 녹이는 것 말고 따로 할 일이 없다.

이 앱이 노리는 검색어와, 각 필드 어디에 심어 뒀는지:

| 검색어 | 앱 이름 | 짧은 설명 | 전체 설명 |
|---|---|---|---|
| 알바 비교 / 알바 시급 | ✅ | ✅ | ✅ |
| 일자리 비교 / 채용공고 비교 | ✅ | ✅ | ✅ |
| 실질시급 / 시급 비교 | — | ✅ | ✅ (전용 단락) |
| 통근 시간 / 출퇴근 | — | ✅ | ✅ |
| 워라밸 / 퇴근 시간 | — | ✅ | ✅ |
| 이직 고민 / 직장 선택 | — | — | ✅ |
| 육아 병행 알바 | — | — | ✅ |

**하지 말 것** (Play 정책 위반 → 등록 거부 사유):
- 설명 끝에 키워드를 쉼표로 나열하는 것(`알바,구직,시급,연봉,...`)
- "1위 앱", "최고의" 같은 근거 없는 순위 주장
- 다른 앱 이름(알바천국, 사람인, 알바몬 등)을 제목·짧은 설명에 넣는 것.
  전체 설명 안에서 "그 앱에서 복사해 붙여넣는 방법" 맥락으로 쓰는 건 괜찮지만,
  브랜드를 검색 유인으로 쓰면 상표권 신고 대상이 된다. 위 전체 설명 초안에는 타사 앱 이름을 넣지 않았다.

**출시 후 관리**: Play Console → 실적 → 사용자 획득 → 'Google Play 검색어'에서 실제 유입 검색어를 보고,
2~4주 뒤 짧은 설명을 그 검색어에 맞춰 한 번 고쳐 쓰는 게 초기 ASO에서 가장 효과가 크다.

## 9. 데이터 보안(Data safety) 폼

Google 정책상 "기기 밖으로 전송되지 않는 데이터는 수집(collected)으로 취급하지 않는다"
(https://support.google.com/googleplay/answer/11416267).

- **"앱에서 필수 사용자 데이터 유형을 수집하거나 공유하나요?" → 아니요**
- 데이터 암호화 전송 여부 → 해당 없음(전송 자체가 없음)
- 데이터 삭제 요청 방법 → 해당 없음(앱 삭제 시 함께 삭제)

앱 화면을 GitHub Pages에서 받아오므로 GitHub 서버에 일반적인 접속 로그(IP)가 남지만,
이는 웹페이지를 여는 모든 앱에 공통인 네트워크 동작이고 앱이 수집·보관하는 게 아니다.
`docs/privacy.html` 5항에 이 점을 명시해 뒀다.

## 10. 앱 콘텐츠 선언

- 광고: **없음** (Play Console '광고' 항목 → 아니요)
- 인앱 구매: 없음
- 타겟 연령: **만 18세 이상** — 13~17세를 포함시키면 Families 정책(추가 심사·광고 규제)이 걸린다. 구직 앱이라 18세 이상으로 두는 게 맞다.
- 정부 앱: 아니요 / 금융 앱: 아니요 / 건강 앱: 아니요
- 민감 권한 선언: **해당 없음** — 이 앱은 권한을 하나도 선언하지 않는다(v1.0.0에서 미사용 `POST_NOTIFICATIONS`를 제거함).

## 11. TWA(웹 래퍼) 관련 심사 주의

이 앱은 Trusted Web Activity로, Digital Asset Links 검증을 통과한 정식 방식이다
(`https://bjgb1004-afk.github.io/.well-known/assetlinks.json`, SHA-256 지문 등록 완료).
다만 Play의 "최소한의 기능(Minimum Functionality)" 정책은 **단순히 웹사이트를 띄우기만 하는 앱**을
거부한다. 거부를 피하려면 스토어 등록정보가 "웹사이트를 보여주는 앱"이 아니라
"계산·정렬 기능을 제공하는 도구"로 읽혀야 한다 — 위 전체 설명 초안은 그 기준으로 썼다.
심사에서 지적이 들어오면 오프라인 동작(서비스워커), 공유 인텐트 수신, 기기 내 저장을
근거로 회신하면 된다.
