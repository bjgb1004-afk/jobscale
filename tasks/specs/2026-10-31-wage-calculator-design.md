# 임금계산기 설계 (2026-10-31)

(이 파일은 `docs/`가 아닌 `tasks/`에 둔다 — `docs/`는 GitHub Pages로 실제 배포되는 웹앱 루트라,
내부 설계문서를 거기 두면 그대로 사이트에 같이 배포된다.)

## 범위

- 별도 화면(탭) "계산기"를 추가한다. 기존 "공고 비교" 기능과는 독립적으로 동작한다.
- 사용자가 아는 급여 하나(시급/일급/월급/연봉)를 입력하면, 나머지 단위로 전부 환산해 보여주고,
  4대보험 + 소득세/지방소득세를 뗀 실수령액까지 계산해 보여준다.
- "월급 받는데 평균 시급이 얼마인지 궁금하다"는 요구도 이 흐름에 포함된다(월급을 입력값으로 선택하면 됨).

## 입력값

| 필드 | 설명 |
|---|---|
| 급여 유형 | 시급 / 일급 / 월급 / 연봉 중 선택 |
| 급여 금액 | 선택한 유형의 금액(세전) |
| 하루 근무시간 | 시급 환산에 필요 |
| 주당 근무일수 | 일급 환산에 필요 |
| 부양가족 수(본인 포함) | 소득세 인적공제 계산에 필요. 기본값 1(본인만) |

## 계산 로직 — 새 파일 `docs/js/wageCalc.js`

`score.js`와 동일한 패턴(순수 함수, DOM 접근 없음, 브라우저/node 양쪽 동작, UMD 래퍼).

### 1. 단위 환산 (세전)
기존 `score.js`의 `WEEKS_PER_MONTH = 4.345`를 그대로 가져와 쓴다(의존하지 않고 값만 복제 —
`shareParse.js`가 이미 그렇게 하고 있음, 패턴 일치).

```
월급(원) = 시급 × 하루근무시간 × 주당근무일수 × 4.345
월급(원) = 일급 × 주당근무일수 × 4.345
연봉(원) = 월급(원) × 12
```
나머지 방향(월급→시급 등)은 역산.

### 2. 4대보험 (근로자 부담분만, 월급 기준)
비율은 매년 바뀌므로 파일 맨 위 `RATES_2026` 객체에 모아둔다. 매년 1월 국가에서 고시하는
새 비율로 이 객체만 교체하면 됨 — 계산 로직은 손댈 필요 없음.

```js
var RATES_2026 = {
  nationalPension: 0.045,      // 국민연금
  healthInsurance: 0.03545,    // 건강보험
  longTermCare: 0.1295,        // 장기요양보험 — 건강보험료 × 이 비율
  employmentInsurance: 0.009   // 고용보험
};
```
(산재보험은 전액 사업주 부담이라 근로자 공제 대상이 아님 — 계산에서 제외.)

### 3. 소득세 — 근로소득 간이세액표 산출 공식

국세청 간이세액표 자체(수천 행)를 베끼지 않고, 그 표를 만들 때 쓰는 공식을 구현한다
(소득세법 §47/§55/§59 기준). 네이버 계산기도 같은 구조의 공식을 쓰는 것으로 알려져 있어
결과가 거의 일치하지만, 1원 단위까지 완전히 같다고 보장하지는 않는다.

```
연간급여추정 = 월급 × 12

근로소득공제 =
  연간급여 ≤ 500만        : 연간급여 × 70%
  연간급여 ≤ 1,500만      : 350만 + (연간급여-500만) × 40%
  연간급여 ≤ 4,500만      : 750만 + (연간급여-1,500만) × 15%
  연간급여 ≤ 1억          : 1,200만 + (연간급여-4,500만) × 5%
  연간급여 > 1억           : 1,475만 + (연간급여-1억) × 2%

근로소득금액 = 연간급여추정 - 근로소득공제
인적공제 = 150만 × 부양가족수(본인포함)
과세표준 = max(0, 근로소득금액 - 인적공제)

산출세액 = 과세표준에 2024년 기준 7단계 누진세율 적용 (§55):
  1,400만 이하        : ×6%
  5,000만 이하        : 84만 + 초과분×15%
  8,800만 이하        : 624만 + 초과분×24%
  1.5억 이하          : 1,536만 + 초과분×35%
  3억 이하            : 3,706만 + 초과분×38%
  5억 이하            : 9,406만 + 초과분×40%
  10억 이하           : 1억7,406만 + 초과분×42%
  10억 초과           : 3억8,406만 + 초과분×45%

근로소득세액공제 (§59, 단순화 — 급여수준별 공제한도 세부조정은 생략):
  산출세액 ≤ 130만 : 산출세액 × 55%
  산출세액 > 130만 : 71만5천 + (산출세액-130만) × 30%

연간결정세액 = max(0, 산출세액 - 근로소득세액공제)
월 소득세 = 연간결정세액 / 12
월 지방소득세 = 월 소득세 × 10%
```

**의도적으로 생략한 부분 (ponytail: 간소화 지점)**
- 자녀세액공제, 경로우대공제 등 세부 추가공제는 넣지 않음 — 기본 인적공제(1인당 150만)만 반영.
  나중에 "자녀 수" 입력을 추가하면 이 부분만 확장하면 됨.
- 근로소득세액공제의 급여수준별 한도 구간(총급여 3,300만/7,000만 기준 축소구간)은 반영하지
  않음 — 고소득 구간에서 네이버와 오차가 커질 수 있음.
- ~~비과세 소득(식대 등)은 고려하지 않음~~ → 네이버 계산기와 금액 차이가 커서(기본 식대
  비과세 20만원) 2026-11-01 추가. 월급에서 비과세액(기본 20만원)을 뺀 금액을 4대보험·
  세금 산정 기준으로 쓴다. `netPay(monthlyWon, dependents, rates, taxFreeAmount)`.

이 간소화들은 "정확히 네이버와 일원 단위까지 일치"가 아니라 "대략적인 실수령액 감"을
주는 목적에는 충분하다고 판단함. 더 정확하게 하려면 범위가 한 단계 더 커짐.

## 화면

- 상단 네비게이션에 "계산기" 버튼 추가 → 새 화면 `view-calculator`.
- 입력 폼 → 결과 요약 카드(단위별 환산 금액 + 4대보험/세금 내역 + 실수령액).
