앱 이름: 직장비교 (패키지 io.github.bjgb1004_afk.jobscore) · 최종 수정일: 2026년 9월 20일

1. 수집하는 개인정보

직장비교는 어떤 개인정보도 수집하지 않습니다. 회원가입이 없고, 로그인이 없으며, 이름·연락처·위치·연락처 목록·기기 식별자를 요구하거나 읽지 않습니다.

2. 입력한 내용이 저장되는 곳

사용자가 등록한 채용공고(회사명, 급여, 근무시간, 통근시간 등)와 중요도·필수조건 설정은 기기 안의 브라우저 저장소(localStorage)에만 저장됩니다. 이 내용은 외부 서버로 전송되지 않으며, 개발자를 포함해 누구도 열람할 수 없습니다. 앱을 삭제하거나 저장소를 비우면 함께 삭제됩니다.

3. 사용자가 직접 내보내는 경우

  • 백업 내보내기: 사용자가 버튼을 눌렀을 때만 JSON 파일이 기기에 저장됩니다. 파일을 어디에 보관하고 누구에게 전달할지는 전적으로 사용자가 정합니다.
  • 결과 링크 공유: 사용자가 버튼을 눌렀을 때만, 등록한 공고 내용이 링크 주소 안에 담긴 형태로 만들어집니다. 이 링크는 서버에 올라가지 않고 사용자가 전달한 상대만 열 수 있습니다. 공유한 링크에는 공고 내용이 들어 있으므로, 공개 게시판 등에 올릴 때는 주의해 주세요.

4. 광고·분석 도구

광고를 넣지 않았고, 분석(애널리틱스)·추적 도구를 일절 사용하지 않습니다. 제3자에게 제공하거나 판매하는 정보도 없습니다.

5. 네트워크 접속

앱 화면은 GitHub Pages(bjgb1004-afk.github.io)에 올려둔 웹 화면을 불러오는 방식이라, 화면을 받아오는 과정에서 GitHub의 서버 기록에 일반적인 접속 기록(IP 주소 등)이 남을 수 있습니다. 이는 웹페이지를 여는 모든 경우에 공통으로 발생하는 일이며, 앱이 별도로 수집하거나 보관하지 않습니다. 한 번 화면을 받아둔 뒤에는 인터넷 없이도 사용할 수 있습니다.

6. 어린이 개인정보

이 앱은 만 18세 이상 구직자를 대상으로 하며, 어린이를 겨냥해 만들지 않았고 어린이로부터 어떤 정보도 수집하지 않습니다.
